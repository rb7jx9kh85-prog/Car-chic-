# Car Chic — refonte 2026

Refonte complète du site de Car Chic, atelier de detailing automobile à Corseaux, près de Vevey.

## Direction créative

- univers automobile premium, sombre et technique ;
- accent lime distinctif pour les actions et détails importants ;
- interactions de scroll, transitions d’images, comparateur avant/après et navigation mobile immersive ;
- expérience responsive et respect de `prefers-reduced-motion` ;
- contenu commercial fondé sur les prestations, tarifs et coordonnées publiques de Car Chic.

## Lancer le projet

```bash
npm install
npm run dev
```

Le site utilise Next.js, React et Tailwind CSS. Les visuels de services proviennent du site public existant de Car Chic et restent la propriété de leur auteur.
